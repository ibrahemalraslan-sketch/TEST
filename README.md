# بنك اختبارات كلية الطب البشري

موقع ثابت بسيط (بدون سيرفر أو قاعدة بيانات) لاستعراض اختبارات كلية الطب مقسّمة على
٦ سنوات دراسية، كل سنة فيها فصلان، وكل فصل فيه مواده. تقدّم الطالب (اختبارات
مكتملة / قيد التقدم) يُحفظ تلقائياً في متصفح كل طالب (localStorage) — لا حاجة لأي
تسجيل دخول أو سيرفر.

## هيكل الملفات

```
index.html              الصفحة الرئيسية (قائمة السنوات الست)
year.html                صفحة السنة (فصلان)
semester.html             صفحة الفصل (قائمة المواد)
subject.html               صفحة المادة (قائمة الاختبارات)
quiz.html                    محرك الاختبار (يعمل لأي اختبار عبر ?exam=<id>)
assets/site.js                 دوال مشتركة: تحميل المنهج + تتبع التقدم
data/curriculum.json             بنية السنوات/الفصول/المواد/الاختبارات
data/exams/<exam-id>.json          بنك أسئلة كل اختبار على حدة
```

## كيف تضيف اختباراً جديداً

1. **جهّز ملف الأسئلة** بصيغة JSON في `data/exams/اسم-الاختبار.json`. الصيغة:

```json
[
  {
    "id": 1,
    "question": "نص السؤال...",
    "options": { "A": "...", "B": "...", "C": "...", "D": "..." },
    "correctLetter": "B",
    "hint": "تلميح اختياري",
    "correctExplanation": "شرح الإجابة الصحيحة",
    "examTrap": "تنبيه اختياري لفخ شائع بالامتحان",
    "optionReviews": { "A": "سبب خطأ هذا الخيار", "C": "..." },
    "referenceDocument": "المحاضرة رقم كذا",
    "referencePage": "ص 5"
  }
]
```

   الحقول الإلزامية: `id`, `question`, `options`, `correctLetter`, `correctExplanation`.
   البقية اختيارية (تُعرض فقط إذا وُجدت).

2. **سجّل الاختبار** داخل `data/curriculum.json`، ضمن المادة المناسبة (ابحث عن
   السنة → الفصل → المادة، وأضف عنصراً جديداً في مصفوفة `exams`):

```json
{
  "id": "معرّف-فريد-للاختبار",
  "title": "اسم الاختبار كما يظهر للطالب",
  "subtitle": "وصف قصير اختياري",
  "author": "اسم من أعدّ الاختبار (اختياري)",
  "file": "data/exams/اسم-الاختبار.json"
}
```

   `id` يجب أن يكون فريداً على مستوى الموقع كله (يُستخدم كمفتاح لحفظ تقدم الطالب).

3. احفظ، وارفع (commit + push) — الاختبار سيظهر تلقائياً في صفحة المادة.

## كيف تضيف/تعدّل مادة أو سنة أو فصل

كل شيء موجود في `data/curriculum.json` فقط — لا حاجة لتعديل أي HTML. عدّل الأسماء
أو أضف/احذف مواد بحرية، وسيتحدث الموقع تلقائياً بمجرد رفع الملف.

## النشر على GitHub Pages

1. أنشئ مستودعاً جديداً على GitHub وارفع كل هذه الملفات إليه.
2. من إعدادات المستودع Settings → Pages، اختر Branch: `main` والمجلد `/ (root)`.
3. بعد دقيقة أو دقيقتين سيصبح الموقع متاحاً على رابط من نوع:
   `https://<اسم-المستخدم>.github.io/<اسم-المستودع>/`
4. أي تعديل لاحق: عدّل الملف مباشرة على GitHub (أو من جهازك وادفعه بـ `git push`)
   وسيُنشر تلقائياً خلال دقائق.

## ملاحظات مهمة

- **الحفظ محلي فقط**: تقدم كل طالب محفوظ في متصفحه هو فقط (لا يُشارك بين الأجهزة
  ولا يظهر لك كمُعِدّ للموقع). إن أردت لاحقاً حسابات مستخدمين ومزامنة عبر الأجهزة،
  هذا يحتاج خدمة خلفية بسيطة (مثل Firebase) — الموقع الحالي مصمم ليبقى بسيطاً بدون
  ذلك.
- **لا يوجد بناء (build step)**: الموقع HTML/CSS/JS خام بالكامل، يعمل بفتح الملفات
  مباشرة أو استضافتها على أي استضافة ثابتة (GitHub Pages, Netlify, Vercel...).
- لتجربة الموقع محلياً قبل الرفع، شغّل خادماً محلياً بسيطاً من داخل مجلد الموقع
  (المتصفحات تمنع `fetch` على ملفات `file://` مباشرة):
  ```
  python3 -m http.server 8000
  ```
  ثم افتح `http://localhost:8000` في المتصفح.
